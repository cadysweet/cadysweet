# Cady Pay — حسابات كادي الرسمية

نسخة GitHub Pages مستقلة: React في المتصفح فقط، دون خادم تطبيق أو قاعدة بيانات.

## البناء والتحقق

```sh
npm ci --ignore-scripts
npm audit --audit-level=high
npm test
npm run build
```

البناء في `dist/`. قبل طلب دمج تحديث، انسخ محتويات `dist/` إلى جذر المستودع، ثم شغّل `npm run verify:published`. يفحص ذلك تطابق الملفات المنشورة مع المصدر المقفل بدل قبول تعديلات يدوية على الحزمة المبنية.

مصدر الواجهة `page.tsx` و`globals.css`، وإجراءات المتصفح في `browser-safety.ts` والصوت في `copy-sound.ts`. لا تعدّل أرقام المصارف دون مستند معتمد ومراجعة مستقلة.

## حدود الحماية

- سياسة CSP موجودة في HTML وتمنع السكربتات الخارجية والتنفيذ المضمن والاتصال والنماذج والإطارات التي تنشئها الصفحة.
- لا يعرض التطبيق الحسابات عند فتحه داخل إطار. هذا إجراء على مستوى التطبيق؛ ليس ترويسة `frame-ancestors` أو `X-Frame-Options` من الخادم.
- ضبط `frame-ancestors` و`nosniff` و`Permissions-Policy` كترويسات يتطلب طبقة استضافة تتيح ذلك. لا يُدعى أنها مفعلة بمجرد إضافة وسم HTML.
- التخزين المحلي اختياري؛ رفضه لا يمنع الوصول إلى رابط المصرف.
- تفعيل المصادقة الثنائية وحماية حساب GitHub منفصلان عن كود الصفحة.
- بيانات النوران ما زالت تحتاج تأكيدًا رسميًا للمطابقة بين رقم الحساب وIBAN قبل اعتماد الإطلاق.
